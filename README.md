# Weather Overlays Free

**4 looping weather overlays as PNG sprite sheets, free, for any engine.** Every frame is a
seamless tile: repeat it across the screen, at any size. Each comes in three sets: 256 px and
128 px HD, and pixel art drawn at 64 px, not shrunk.

### Want more?

**[Weather Overlays](https://heyheythere.itch.io/weather-overlays)** has 18: heavy rain and a
storm, heavy snow and a blizzard, thick fog, cloud shadows, petals, ash, dust, embers, fireflies,
a sandstorm, bubbles and sparkles. Same sheets, same player.

### What's inside

- **Light rain**, **light snow**, a drifting **fog** and falling autumn **leaves**, each a
  seamless loop in time and across the tile.
- Transparent PNG sheets, 8 frames a row, plus an `effects.json` with every frame size, frame
  count and fps, and a GIF preview of each.
- **Godot 4 player included:** `WeatherOverlay.add(self, "rain_light")` covers the screen and
  fades in. Import steps for Unity and GameMaker in the README.

### Compatibility

- **Any engine** that draws a repeating texture or a tiled sprite: Unity, GameMaker, Godot,
  Defold, Construct, Phaser, LÖVE, MonoGame.
- The Godot player: Godot **4.3 to 4.7**, tested on both ends and on every renderer.
